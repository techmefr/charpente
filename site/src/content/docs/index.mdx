## Three independent axes

<CardGrid>
  <Card title="The theme" icon="seti:css">
    Says what a skeleton looks like: `solid`, `outline`, `dots`, `cyberpunk`, `web` and six seasonal themes.
  </Card>
  <Card title="The motion" icon="rocket">
    Says how it moves: `shimmer`, `pulse`, `wave`, `glitch`, alone or combined.
  </Card>
  <Card title="The timing" icon="pencil">
    Says when: a delay before appearing, to avoid flicker on fast loads, and an offset between elements.
  </Card>
</CardGrid>

```ts title="charpente.config.ts"
import { defineCharpente } from 'charpente'

export default defineCharpente({
  defaultTheme: 'cyberpunk',
  motion: ['shimmer', 'glitch'],
  timing: { delay: 120, stagger: 40 },
  colorScheme: { dark: '[data-theme="dark"]' },
})
```
